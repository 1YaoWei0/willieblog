## Installing Huamei 365® D365FO Tools for Visual Studio

To improve development efficiency in Dynamics 365 Finance and Operations (D365FO), the **Huamei 365® D365FO Tools** extension offers a suite of useful generators and helpers. This blog post provides a quick guide to installing this extension in Visual Studio 2022.

### 🔧 Step 1: Open the Extensions Menu

In Visual Studio 2022, go to the top menu and click **Extensions**.

{% asset_img "Picture1.png" "Picture1" %}

---

### 🔍 Step 2: Browse Extensions

In the Extensions dropdown, select **Manage Extensions**. In the Extension Manager, go to the **Browse** tab and use the search bar to look for `Huamei 365® D365FO Tools`.

{% asset_img "Picture2.png" "Picture2" %}

{% asset_img "Picture3.png" "Picture3" %}

{% asset_img "Picture4.png" "Picture4" %}

---

### ✅ Step 3: Locate and Install the Extension

Find **Huamei 365® D365FO Tools** in the search results. Click **Install** on the right-hand panel.

{% asset_img "Picture4.png" "Picture4" %}

---

### 📋 Requirements

* **Visual Studio 2022 version 17.13.+**
* The extension is designed specifically for D365FO development and may not work outside this context.
